# Equipo Horizonte

Sitio colaborativo de presentación del equipo para el taller de Frameworks Frontend con TypeScript y Bootstrap.

## Equipo

- **David Luna** - desarrollo frontend y coordinación
- **Valentina Burbano** - experiencia de usuario y accesibilidad
- **Santiago Urbina** - arquitectura frontend y testing

## Flujo de trabajo

- `main`: versión estable. La integración final queda pendiente de revisión manual.
- `develop`: rama de integración del equipo.
- `feature/profile-nombre`: página individual de cada integrante.
- `feature/add-nombre-navigation`: navegación y card del integrante en la página principal.

Toda funcionalidad se integra mediante Pull Request simulado, revisión de otro integrante y commits convencionales. Los commits de revisión usan `⚠️` para señalar hallazgos y `✅` para registrar su solución.

## Ejecución local

Abrir `index.html` en el navegador. No se requiere instalación: Bootstrap se carga desde CDN.

## Estado de integración

Los perfiles y sus accesos están integrados en `develop`. La promoción de `develop` hacia `main` se deja intencionalmente pendiente para realizar la revisión final de forma manual.
